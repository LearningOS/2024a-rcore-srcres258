# 编程作业

实现的功能：

1. 为 `Inode` 实现新增了 `hard_link_inode_id`、`query_hard_link_names` 等工具方法。

2. 在 OS 层面的实现中，新增 `file_stats` 函数用以查询文件的详细信息，以及 `create_hard_link` 等硬链接操作函数用以修改文件系统中的硬链接。

3. 最后在此基础上，实现 `sys_linkat`、`sys_unlinkat`以及`sys_stat` 系统调用，用以实现文件系统的软链接、删除软链接以及查询文件信息的功能。

# 问答作业

1. 在我们的easy-fs中，root inode起着什么作用？如果root inode中的内容损坏了，会发生什么？

    **答：** root inode 是整个文件系统的根索引，用以保存其下所有文件内容的子索引。若 root inode 损坏，将导致子索引无法正常被查询到，从而导致该文件系统上的所有文件无法被访问，可认为该文件系统损坏。

2. 举出使用 pipe 的一个实际应用的例子。

    **答：** 如 Linux 下的 `tee` 命令，该命令的作用是通过管道读入前置程序的标准输出，将输出导流到终端上的同时也将其写入到指定的文件中。

3. 如果需要在多个进程间互相通信，则需要为每一对进程建立一个管道，非常繁琐，请设计一个更易用的多进程通信机制。

    **答：** 可在内核层面设计一个类似 Windows 系统中 Win32 API 下的消息队列机制，进程间可相互发送消息，各进程持续轮询接收其他进程发来的消息，达到进程间通信的目的。
